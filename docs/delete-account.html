앱 내 계정 삭제 방법

1단계. FitLog 앱 실행 후 로그인
2단계. 하단 탭 메뉴에서 더보기 탭 선택
3단계. 하단의 계정 삭제 버튼 탭
4단계. 확인 메시지에서 삭제 확인 선택

삭제되는 데이터

  • 계정 정보 (이름, 이메일, 카카오 계정 연동)
  • 운동 기록, 식단 기록, 바디로그 등 모든 활동 데이터
  • 업로드한 식단 사진
  • 알림 기록
  • 구독 정보 (RevenueCat)
